## Features
- Monthly & quarterly forecast views
- Weighted forecast calculations
- Commit vs Best Case forecasting
- Pipeline stage coverage
- Rep contribution analysis
- Sandbagging detection
- Drill-down filtering
- Excel upload support

## Tech Stack
- HTML
- JavaScript
- Chart.js
- XLSX.js

## How to Use
1. Open `dashboard.html`
2. Upload a pipeline Excel file
3. Explore the dashboard visuals and forecasts

## Example Inputs
Expected columns:
- Deal Amount
- Stage
- Forecast Category
- Close Date
- Owner
- Probability (%)

## Notes
All calculations run locally in-browser.
No data is uploaded externally.
